## Architecture livrée

### 1. `src/app/not-found.tsx` (Server Component, root-level)

Catch-all 404 brandée. **Décision architecturale clé** : la 404 vit au root et non dans `[locale]/` parce que :

- Le root layout `src/app/layout.tsx` est intentionnellement un passthrough (le commentaire historique dit : _"the real `<html>`/`<body>` live in `[locale]/layout.tsx` so the `lang` attribute always reflects the active locale"_).
- Avec next-intl en `localePrefix: 'as-needed'`, un path totalement non-matché ne peut pas atterrir de manière fiable sur le segment `[locale]`. Next.js render le not-found root et exige `<html>`/`<body>` à ce niveau.
- Première implémentation dans `[locale]/not-found.tsx` a déclenché l'erreur runtime _"Missing `<html>`/`<body>` tags in the root layout"_. Refactor `9cf89ba` pour migrer au root.

**Caractéristiques** :

- Bilingue FR + EN (langues v1.0 publique d'après `CLAUDE.md`).
- Locale picked from `NEXT_LOCALE` cookie (set par next-intl middleware) → fallback `accept-language` header → fallback FR.
- Cockpit CTA route correctement vers `/app` (FR) ou `/en/app` (EN).
- Native `<a>` href, eslint-disabled inline avec rationale (le 404 ne doit pas dépendre du runtime next/link qui peut être lui-même défaillant).
- Fraunces (var(--font-display)) sur le H1 + brand-700 indicator + token system pleinement utilisé.
- `generateMetadata` émet `robots: { index: false, follow: false }`.

### 2. `src/app/[locale]/error.tsx` (Client Component)

Error Boundary route-level avec `'use client'`, props `{ error, reset }`.

- `useTranslations('errors.boundary')` → tous les 5 locales supportés.
- `role="alert"` sur le main pour les screen readers.
- Retry button → `reset()` (signature standard Next.js).
- Home link → `/` via `@/i18n/navigation`.
- Logger client-side : `console.error('[error-boundary] caught', { digest: error.digest })` — **uniquement le digest, jamais le message brut** (PII safety).
- Fraunces title + tokens design.

### 3. `src/app/global-error.tsx` (Client Component, root)

Last-resort fallback quand le shell entier est cassé. Re-render `<html>`/`<body>` inline.

- Pas d'accès à NextIntlProvider (par design — global error boundary remplace le root layout).
- Copie hardcodée FR + EN, picked via `document.documentElement.lang`.
- Native `<a>` pour le home link (eslint-disabled inline) — un fallback qui survit même si le router Next.js a crashé.
- Import explicite de `./globals.css` pour avoir Tailwind.

### 4. i18n — `errors.notFound` + `errors.boundary`

Ajoutés aux 5 locales avec **parité parfaite** (validée en test) :

```json
"errors": {
  "notFound": { "title", "description", "ctaHome", "ctaCockpit" },
  "boundary": { "title", "description", "ctaRetry", "ctaHome" }
}
```

Traductions natives (pas de placeholders FR) : fr-BE, en, de-DE, es-ES, nl-BE.
