# Seuls les 180 mots vus au moins trois fois ont été examinés : un mot isolé est

# dont `tryptique`, présent dans 8 fichiers.

# documents** plutôt qu'admises ici. Elles ne sont donc plus soulignées parce
# qu'elles n'existent plus.
#
# Deux ne l'ont PAS été, et c'est délibéré : `tryptique` reste dans le nom de
# fichier `docs/prs/PR-BETA-3-capacite-tryptique-report.md` et dans un
# identifiant de test. Un nom de fichier est un identifiant, pas de la prose ;
# le renommer casserait des liens pour corriger une orthographe que personne ne
# lit comme un mot. Ces occurrences sont citées entre accents graves, donc hors
# périmètre — et le mot reste signalé s'il réapparaît dans une phrase.
#
# La règle tient : ajouter un mot ici, c'est déclarer qu'il est juste — pas
# qu'on est fatigué de le voir.
#
# Deux corrections ont été ANNULÉES après relecture du contexte, et les mots
# admis ici à la place. Elles disent quelque chose d'important sur la limite de
# l'exercice : corriger une faute sans lire autour d'elle, c'est réécrire.
#
#   budgetaire  — `docs/AUDIT-GITHUB-2026-04.md` cite VERBATIM la description
#                 GitHub du dépôt, et la ligne suivante dit « ⚠️ Pas d'accents ».
#                 L'accent ajouté rendait l'audit auto-contradictoire.
#   carrié      — coinage de @thierry dans son propre handoff (« son contenu
#                 utile est carrié dans #224 »), de l'anglais *to carry over*.
#                 « charrié » existe en français mais dit autre chose. On ne
#                 réécrit pas les mots de quelqu'un dans son compte rendu.
